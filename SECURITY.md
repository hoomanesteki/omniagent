# Security Policy

## Supported Versions

Security updates are applied to the latest `main` branch. I recommend upgrading
to the most recent release or commit if you encounter a security issue.

## Reporting a Vulnerability

If you discover a security vulnerability, please report it privately.

- website: https://esteki.ca
- Please include: a detailed description, steps to reproduce, potential impact,
  and any suggested fixes.

I will acknowledge receipt within 72 hours and provide updates as I
investigate. I may ask for additional information or clarification.

## Coordinated Disclosure

Please avoid filing public issues for security vulnerabilities. I appreciate
coordinated disclosure so we can address issues before public release.
